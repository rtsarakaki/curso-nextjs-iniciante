# 🎮 Código das Aulas - Curso Next.js

## 🚀 Como Executar

### **1. Instalar Dependências**
```bash
npm install
```

### **2. Executar o Projeto**
```bash
npm run dev
```

Acesse [http://localhost:3000](http://localhost:3000)

  - 8 cartas com emojis
  - Sistema de pontuação
  - Contador de movimentos
  - Animações de virada
  - Mensagem de vitória
- **Tecnologias**: React, TypeScript, CSS Grid
- **Conceitos**: Estado, eventos, lógica de programação

## 🔧 Personalização

### **Aula 1 - Personalizar o Site:**
1. Abra `src/aulas/aula-01/PrimeiroSite.tsx`
2. Substitua `[SEU NOME]` pelo seu nome
3. Modifique as cores dos gradientes
4. Adicione suas próprias informações
5. Mude os emojis e textos

### **Aula 2 - Personalizar o Jogo:**
1. Abra `src/aulas/aula-02/MemoryGame.tsx`
2. Modifique o array `emojis` com seus emojis favoritos
3. Mude as cores do fundo
4. Ajuste o número de cartas
5. Personalize as mensagens

## 🎨 Cores Disponíveis

### **Gradientes de Fundo:**
- `from-blue-400 to-purple-600` (Azul para roxo)
- `from-pink-400 to-red-500` (Rosa para vermelho)
- `from-green-400 to-blue-500` (Verde para azul)
- `from-yellow-400 to-orange-500` (Amarelo para laranja)

### **Cores de Cartas:**
- `bg-blue-600` (Azul)
- `bg-green-600` (Verde)
- `bg-purple-600` (Roxo)
- `bg-pink-600` (Rosa)

## 🔍 Debugging

### **Se algo não funcionar:**
1. **Verifique o console** do navegador (F12)
2. **Confirme que o servidor** está rodando
3. **Recarregue a página** (Ctrl+F5)
4. **Verifique os imports** dos componentes

### **Erros Comuns:**
- **Erro de import**: Verifique o caminho do arquivo
- **Erro de sintaxe**: Verifique chaves e parênteses
- **Erro de TypeScript**: Verifique os tipos das variáveis
